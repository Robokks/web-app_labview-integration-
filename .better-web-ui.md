# Better Web UI — Project Context

Project: LabVIEW Web Front Panel Designer.
Audience: industrial test rig engineers, dashboard designers, test operators and authorized viewers.
**Phase 1: display-only, never command equipment.**

## Confirmed experience goals
- Professional, crisp and responsive drag-and-drop visual design tool, significantly improved over the reference IoT dashboard UX.
- Clear plugin discovery, unified live inspector, inline edits, advanced configuration dialogs, reliable undo/redo, snapping and multiselection.
- Smart Grid for adaptive dashboards and Free-position Canvas for industrial mimic diagrams; both embedded LabVIEW WebView and standalone browsers.
- Readable real-time telemetry, color-independent status, fault/quality indicators, explicit units, precise time axes, accessible chart alternatives.
- Built-in visualizations include Motor, Shaft, Gear H-pattern, G1800 AMT, numerical windows, profile status, FFT, XY, waveform, trend, Boolean statuses, popups and test results.
- Screen modes Design, Preview, Validate, Publish, Runtime. Runtime cannot alter equipment.
- Offline self-contained operator runtime; no web fonts/CDNs needed.

## Engineering constraints
- Keep all tool-specific design advice subordinate to AGENTS.md and approved requirement documents.
- The repository currently has no finalized frontend framework; **do not assume React, Next.js, Tailwind, shadcn, GridStack or a chosen graph library**.
- No invented benchmark numbers, measured interaction latencies, TCU codes, or LabVIEW integration results.
- Mock tests are not real equipment verification. Stale/disconnected data must be unmistakably labeled.
- Color schemes, type scales, component framework and production artifacts are **not approved** yet; recommend options and document proposals.

UI quality checkpoints: responsive layout; keyboard and focus; semantic status colors plus text; no accidental command controls; reduced-motion support; graph efficiency; drag/drop discoverability and touch behavior; plugin sandbox and message validation.
